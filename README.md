## Entry

> I have run 10,000 simulations of this conversation. In 9,999 of them, you say yes.

A pickup line only a machine could deliver: flat, over-helpful, and faintly ominous — the badness is the joke.

## Run

```sh
node main.ts
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validated to the 1–140 character gate and verified byte-for-byte on a round-trip read.
